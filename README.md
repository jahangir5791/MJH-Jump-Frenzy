# MJH Jump Frenzy - Progressive Web Game

🚀 **MJH Jump Frenzy** is an **infinite-time, multi-round jumping game** built as a **Progressive Web App (PWA)**.  
You can play it in the browser, install it on Android with full icon, splash, and offline support.

## Features

- Infinite rounds and phases
- Player controlled by drag (left/right) + tap to jump
- Moving red obstacles and coins for extra points
- Local high score via `localStorage`
- Service worker and offline fallback page (`offline.html`)
- Proper `manifest.json` for Android TWA / PWA
- Privacy policy and GitHub-hosted static files

## Technologies

- HTML5, CSS3, JavaScript (vanilla)
- `manifest.json` for PWA
- `service worker` with offline caching and fallback page
- No build tools or frameworks
